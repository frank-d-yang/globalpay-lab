# MVP Scope

## Customer and access

- Enterprise customer profile
- Sandbox API key
- Basic user roles

## Money movement

- AUD, USD, and SGD wallets
- Payment creation and lifecycle
- Idempotent payment requests
- Mock provider processing
- Refunds and ledger reversals

## Financial records

- Double-entry ledger
- Immutable journal history
- Available, pending, and ledger balance views
- Settlement batches
- Provider fees and net settlement amounts

## Integration

- OpenAPI documentation
- Signed webhook events
- Retry history and manual redelivery
- Provider adapter interface

## Operations

- CSV settlement-file import
- Automated reconciliation
- Exception classifications
- Basic rule-based risk alerts
- Audit trail
- React operations dashboard

## Delivery

- Automated tests
- Docker setup
- CI pipeline
- Hosted sandbox environment
- Architecture documentation
- English demo
